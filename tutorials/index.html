  • Olympus: Xtrace on HopperOlympus：Hopper 上的 Xtrace

    Chtholly-Boss/Olympus @ 40a887a · 2026-09-29

    Olympus reimplements Xtrace (arXiv:2609.28769) for sm_90. Xtrace traces GPU kernels by splicing probe instructions into compiled SASS, using dead registers and searched control bits so that the kernel's own instructions are left untouched. This tutorial reads each part of the implementation next to the section of the paper that describes it, and compares the results with G-Watch.

    Olympus 是 Xtrace（arXiv:2609.28769）在 sm_90 上的重实现。Xtrace 把探针指令拼接进已编译的 SASS 来追踪 GPU kernel，探针只用死寄存器和搜索出的控制位，kernel 自身的指令保持不动。本教程把实现的每一部分与论文中对应的章节对照阅读，并把结果与 G-Watch 比较。
