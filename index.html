  • Olympus: how a tracer changes nothing it measuresOlympus：一个不改变被测对象的追踪器

    Chtholly-Boss/Olympus @ 21662ef · 2026-10-01

    Olympus is a binary-level intra-kernel event tracing system for NVIDIA GPUs (Hopper and Blackwell). It splices probe code into compiled SASS using only registers proven dead and only its own scoreboards, so the kernel's instructions stay byte-identical and never wait for a probe. This second edition teaches the design bottom-up: it starts at the 128-bit instruction word, then builds one layer at a time — which registers are provably dead, how far apart instructions must issue, what a probe is, how one is fitted to a site and written into the file — and only then runs it, reads the trace, and shows how all of it is checked. Each chapter opens with the contract its layer gives the next and the invariant it protects.

    Olympus 是面向 NVIDIA GPU（Hopper 与 Blackwell）的二进制级 kernel 内事件追踪系统。它把探针代码拼接进已编译的 SASS，只使用被证明已死的寄存器和探针自己的 scoreboard，因此 kernel 自身的指令逐字节不变，也从不为探针等待。第二版自下而上讲设计：从 128 位的指令字起步，然后一层一层往上搭——哪些寄存器可证已死、指令之间必须隔多远发射、探针是什么、如何把一个探针装进一个站点并写进文件——到这时才运行它、读追踪，并展示这一切如何被检查。每章都以该层交给下一层的契约、以及它保护的不变量开篇。
